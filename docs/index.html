What this checker can establish
One expected effect only. A confirmed receipt requires a matching run ID, action ID, target, business key and explicit destination readback. Duplicate or contradictory evidence must be reconciled. A failed attempt does not establish the absence of side effects.
The checker trusts supplied evidence labels; it cannot verify their authenticity, connect to a destination or authorize a retry. Use exact strings for IDs and numeric metadata; the browser version rejects non-safe-integer numeric metadata. JSON object keys should be unique. Synthetic examples are not customer outcomes.
